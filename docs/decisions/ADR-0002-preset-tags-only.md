# ADR-0002: Preset tags only
Date: 2026-10-16 | Status: accepted

**Context:** Community grouping needs comparable data.
**Decision:** Users choose from preset tags; no custom tags. A circle = one food item x one hobby tag.
**Rejected:** Free-form tags (fragmentation, hard to cluster).
**Consequences:** The taxonomy is core product; version it in `data/taxonomy/tags.yaml`.
