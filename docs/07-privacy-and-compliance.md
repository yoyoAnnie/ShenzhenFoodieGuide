# Privacy & compliance (to resolve before Phase 2)

Personal diaries, location, and time-of-day habits are sensitive. Check requirements under China's PIPL before launch.
- Explicit consent for location and notification use
- Data minimization: store derived attributes, not raw diary text, where possible
- Delete-my-data path
- Notification opt-in, caps, mute
- Review platform terms before using any third-party data
