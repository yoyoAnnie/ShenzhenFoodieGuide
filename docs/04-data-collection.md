# Manual data collection

Collect by hand first. Schema: `data/schema/restaurant.schema.json`. Table: `data/restaurants/restaurants.csv`. Tags: `data/taxonomy/tags.yaml`.

## Per place, record
- Name (zh/en), district, address, coordinates, price per head
- Opening hours **and the date you verified them** (late-night accuracy is a core promise)
- Occasion tags, food-item tags (preset only)
- Taste attributes 0-5 from your own visit (anchors)
- Insider note: what to order, when to go, how to get a table
- Source: visited / contributor name / hearsay

## Rules
- Prefer places you or a named contributor have visited.
- Re-verify late-night hours every ~8 weeks.
- Don't copy platform reviews wholesale (terms of service); write your own notes.
